# Project documentation

- `architecture/`: system diagrams, decisions, and data flows.
- `api/`: reviewed OpenAPI contract and safe examples; M3 owns publication.
- `requirements/`: roadmap, starter backlog, labels, GitHub Project setup, and [data/content evaluation plan](requirements/DATA_AND_CONTENT_PLAN.md).
- `meeting-notes/`: dated decisions and action items without sensitive case data.
- `team-guidelines/`: shared team practices and ownership links.

Keep documents reviewed, current, and free of credentials or identifiable child information.
