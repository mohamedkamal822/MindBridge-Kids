# GitHub Project: Development Tracker

Create a project named **MindBridge Kids – Development Tracker** and link it to this repository. A repository admin or project owner should do this in the GitHub UI; no remote project resource has been created by these local setup files.

## Fields

- **Status** (single select): Backlog, To Do, In Progress, In Review, Testing, Done.
- **Priority** (single select): High, Medium, Low.
- **Team** (single select): AI, Mobile, Backend, Data, QA.
- **Assignee** (GitHub user field): use after usernames are confirmed.
- **Start date** (date).
- **Due date** (date).
- **Milestone** (text or single select): Month 1 through Month 8, plus MVP and Release if useful.

## Manual setup

1. Open the repository, choose **Projects → New project**, and create a **Board** view.
2. Name it **MindBridge Kids – Development Tracker** and add the repository as a source.
3. Configure the fields above; group the board by Status and sort by Priority.
4. Create the first-month issues listed in [STARTER_BACKLOG.md](STARTER_BACKLOG.md), apply labels from [LABELS.md](LABELS.md), and set status/priority/team.
5. Set due dates with the team during planning; the table intentionally does not invent calendar deadlines.
6. Add a roadmap view grouped by Milestone and review it weekly with M7.
